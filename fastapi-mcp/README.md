Para executar o projeto, você deve seguir os seguintes passos:

`1.` Executar o docker compose:

* Executar o comando para iniciar os containers:
```bash
docker compose up    ou    docker compose up --build
```
* Em segundo plano:
```bash
docker compose up -d
```

`2.` Parar os containers:

* Executar o comando para parar os containers:
```bash
docker compose down
```

`3.` Acessar o endpoint:

* Acessar o endpoint:
```bash
http://localhost:8000/docs
```

Todos esses serviços estão conectados na rede "app-network" e os dados do MongoDB são persistidos através de volumes.
